# Dipol Ltd. Modernization

## Project Overview
Modernizing the existing `www.dipolltd.com` website using modern web technologies while preserving its original content.

## Technology Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS (tek-ui standards)
- **Components**: Radix UI, Lucide Icons, Shadcn/ui
- **Animations**: Framer Motion
- **Performance**: Optimized for LCP, FID, CLS

## Directory Structure
- `/code`: Next.js application source code
- `/reference`: Original site content, screenshots, and assets
- `/public`: Static assets for the new site

## Getting Started
1. `cd code`
2. `pnpm install`
3. `pnpm dev`
